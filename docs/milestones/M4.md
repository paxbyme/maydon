# M4 — application navigation and contract integration

State: in progress, not accepted.

## Implemented

- Shared Material 3 shell with mobile bottom navigation, tablet rail and extended desktop rail.
- Player Home, Explore, Find Players, Bookings and Profile routes; homepage links to venue/game discovery.
- Separate owner and administration navigation with explicit unavailable states for workflows not yet connected.
- In-session Uzbek Latin, Russian and English language selection, complete ARB keys, localized navigation/content.
- Generated Dart models and Dio operations from OpenAPI, deterministic source hash and CI drift checks for both OpenAPI and Dart output.
- Responsive navigation, locale switching and narrow-screen large-text widget tests.

## Outstanding acceptance work

Authentication screens, native secure credential storage, browser cookie transport, persistent locale preference, live API integration, keyboard/screen-reader validation, contrast verification and representative signed-in journeys remain incomplete. Locale selection currently lasts only for the running application session. Existing venue/game/booking screens explicitly state availability is forthcoming; no sample reservation or false success is displayed.

The generator currently supports the contract's primitive and referenced object schemas plus path parameters; it rejects unsupported schema/parameter shapes so future pagination, arrays and union types require deliberate implementation. Staff response bodies remain untyped maps until the backend declares their response schema.

## Data/API and affected files

No database migration or new server route. Changes cover all three app main files and navigation widget tests, shared design/navigation primitives, three ARB catalogs, generated API client and generator, CI drift checks and milestone documentation.

## Verification

Ten widget tests pass across player (four), owner (three) and admin (three), covering narrow-screen large text, adaptive navigation, all three languages and player discovery actions. Static analysis passes for all three apps, the shared design system and generated API client. ARB completeness and generated contract drift checks pass. Clean build CI for this change set is pending; M4 remains in progress.
