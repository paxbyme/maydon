# M4 — application navigation and contract integration

State: in progress, not accepted.

## Implemented

- Shared Material 3 shell with mobile bottom navigation, tablet rail and extended desktop rail.
- Player Home, Explore, Find Players, Bookings and Profile routes; homepage links to venue/game discovery.
- Separate owner and administration navigation with explicit unavailable states for workflows not yet connected.
- Persistent Uzbek Latin, Russian and English language selection using device preferences, with account preference updates after authentication. Complete ARB catalogs cover navigation, forms and errors.
- Generated Dart models and Dio operations from OpenAPI, deterministic source hash and CI drift checks for both OpenAPI and Dart output.
- Shared identity package connects generated API operations to registration, login, recovery, email/phone verification, MFA enrollment/verification, profile and logout/revoke-all screens.
- Native refresh credentials use platform secure storage; web uses Secure/HttpOnly cookies, CSRF headers and a Web Lock for rotation across tabs. Access tokens remain in memory.
- Responsive navigation, locale switching, narrow-screen large-text, session concurrency/failure and accessibility widget tests.
