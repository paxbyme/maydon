# M3 — identity and scoped access

State: implemented; local acceptance passed, clean CI validation pending. No production release is authorized by this milestone.

## Change set

- Email/password registration, single-use email/SMS verification, password recovery, own profile and locale preference.
- Argon2id passwords, 15-minute signed access tokens, database-checked sessions, hashed rotating refresh credentials, reuse revocation, logout/revoke-all and a fixed 30-day lifetime.
- Browser HttpOnly refresh cookies, exact Origin checks, CSRF protection, no-store authentication responses and explicit mobile transport.
- Redis-backed throttling, resend limits, five-attempt challenges, encrypted delivery envelopes and private local test delivery.
- Administrator TOTP enrollment/verification with password proof, encrypted secrets, replay protection and protected-by-default route guard.
- Explicit resource permission presets and owner-only staff assignment/revocation with audit records.

## Data and API

Migration `202611010004_identity` introduces Session, RefreshCredential and VerificationChallenge plus account/MFA fields. Existing occupancy invariants remain unchanged. Versioned identity and staff endpoints are documented in generated OpenAPI with DTO validation and safe response projections. See [identity](../identity.md) and [API](../api.md).
